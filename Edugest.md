# **Edugest**

* Sistema de gestión educativo, que permite a través de varios módulos llevar un registro de trazabilidad  en base a los estándares y normas exigidas por el Mineduc
* Este cuenta con una gran variedad de módulos, los cuales de no ser requeridos pueden  ser deshabilitados/habilitados



## Libro Digital

* Permite llevar un recuento de la cantidad de alumnos inscritos en cada nivel
* Permite llevar una  planificación de unidades y clases
* El registro de una clase contiene (contenido, detalles de actividad, objetivos de la clase)
* Permite llevar un registro de la asistencia y de anotaciones por cada curso y por cada alumno



## Evaluaciones

* Permite crear y diseñar evaluaciones  presenciales y digitales
* Permite configurar cada evaluación por tipo(calificativa, sumativa, diagnostica, formativa)
* Permite  definir la fecha en la que se habilitara la evaluación
* Permite configurar y crear distintos tipos de preguntas(alternativas, verdadero y falso, desarrollo, relación ente columnas, rellenar espacios en oraciones)
* Permite asignar calificaciones de manera manual y de manera automática



## Calendario

* Permite registrar eventos y actividades  tanto para un curso en especifico como para el establecimiento en general
* Rescata y muestra por cursos las fechas de las evaluaciones próximas y anteriores



## Comunicación 

* Permite publicar anuncios masivos en un tablero digital, tanto para cada curso/ciclo, como para todo el establecimiento
* Permite comunicación directa y privada bidireccional para funcionarios y apoderados
* Muestra si los mensajes fueron leídos a través de un chat interno del sistema



## Biblioteca

* Permite registrar  libros y documentos en un inventario/catalogo
* Permite llevar un registro de prestamos
* Contiene una biblioteca de recursos open-source gratuitos online



## Matricula

* Permite matricular estudiantes nuevos y antiguos, con los datos estándar solicitados del Mineduc
* Permite ver información académica ordenada y filtrada por cada alumno



## Reportes

* Dashboard de análisis de métricas por cada curso
* Permite generar informes de notas
* Permite configurar que notas se incluyen en el informe de notas
* Permite ver y comparar el registro de notas y antecedentes de cada alumno por nivel
